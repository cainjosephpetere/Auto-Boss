AUTO BOSS WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the website.
3. Upload the contents of this folder to your web host (keep the assets folder alongside index.html).

FEATURES
- Responsive mobile mechanic and auto electrician website.
- Brand colours taken from the supplied flyer: deep navy, orange and white.
- Supplied Auto Boss logo and matching favicon.
- Gallery using the supplied workshop photos. Photos have been upscaled 2x and lightly enhanced for contrast, colour and sharpness; enhancement cannot recreate detail that was not in the originals.
- Consultation form prepares a WhatsApp message to +27 60 621 8464. The visitor reviews and sends it in WhatsApp.
- Services and service-area wording based on the supplied flyer.
